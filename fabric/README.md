# ItemLock — Fabric, Minecraft 1.21.11

This folder is the Fabric/Quilt build for **Minecraft 1.21.11**. Other Minecraft versions are built from sibling folders — see the [repository README](../README.md) for the full folder-to-version table and what differs between the variants.

## Requirements

- Minecraft 1.21.11
- [Fabric Loader](https://fabricmc.net/use/) `>=0.19.3` (or Quilt Loader, via its Fabric-compatibility layer)
- [Fabric API](https://modrinth.com/mod/fabric-api) (Quilted Fabric API on Quilt)
- Java 21

## Building from source

```
./gradlew build
```

The output jar is written to `build/libs/`.
